# FWAI starter folder

1. Unzip this into Documents. Keep the name fwai-starter.
2. In VS Code, use File > Open Folder and pick fwai-starter.
3. VS Code asks if you trust the authors. Press Yes, it is your own folder.
4. Ask Kilo Code: Read AGENTS.md and list the rules you must follow before you say a task is done.
5. New project? Duplicate this folder, rename the copy, open the copy.
6. Never paste a key or token into these files. Kilo keeps your key.
